# TwoDism

**TwoDism** — небольшой C#-модуль для создания консольных игр: интерактивных карт, roguelike и текстовых квестов. Он рисует персонажа и функциональные блоки в окне консоли, обрабатывает перемещение с клавиатуры и вызывает действия блоков при взаимодействии с ними.

## Требования

- .NET 8 или новее.
- C# 12 или новее: в коде используются primary constructors и collection expressions.
- Терминал, поддерживающий управление позицией курсора и цветом текста.

В стандартном проекте .NET 8 Console App необходимые пространства имён обычно подключаются через implicit usings. Если они отключены, добавьте в `TwoDism.cs` директивы:

```csharp
using System;
using System.Collections.Generic;
```

## Установка

1. Откройте проект .NET.
2. Добавьте файл `TwoDism.cs` в проект.
3. Используйте типы и методы `TwoDism` из своего кода.

> **Примечание:** сейчас `TwoDism` объявлен без модификатора `public`, поэтому доступен внутри той сборки, в которую добавлен файл. Для использования из другого проекта через отдельную сборку объявление класса нужно изменить на `public static class TwoDism`.

## Быстрый старт

Добавьте функциональные блоки, задайте им символы, цвета и действия, а затем вызовите `Start()`:

```csharp
using System;
using System.Collections.Generic;

// Действие блока: переключает цвет персонажа.
static void ChangeColor(TwoDism.Character character)
{
    character.CharacterColor = character.CharacterColor == ConsoleColor.Green
        ? ConsoleColor.White
        : ConsoleColor.Green;
}

// Непроходимая стена.
TwoDism.AddBlock(new(
    '#',
    ConsoleColor.Red,
    [new TwoDism.Pos(10, 10)],
    TwoDism.Nothing,
    false, // IsWalkable: пройти нельзя
    false  // Disposable: клетка не исчезает
));

// Проходимая одноразовая монета.
TwoDism.AddBlock(new(
    '$',
    ConsoleColor.Green,
    [new TwoDism.Pos(20, 10)],
    ChangeColor,
    true,  // IsWalkable: пройти можно
    true   // Disposable: клетка удаляется при взаимодействии
));

// Запускает игровой цикл. Стрелки — движение, Esc — выход.
TwoDism.Start();
```

Игрок по умолчанию отображается символом `@` белого цвета в координатах `(0, 0)`. Координаты отсчитываются от левого верхнего угла окна консоли: `X` — по горизонтали, `Y` — по вертикали.

## API

### Статические поля и методы `TwoDism`

| Член | Описание |
|---|---|
| `Chr` | Текущий персонаж типа `Character`. По умолчанию — `@`, белый цвет, позиция `(0, 0)`. |
| `FunctionalBlocks` | Список функциональных блоков, добавленных на карту. |
| `AddBlock(FunctionalBlock functionalBlock)` | Добавляет блок в `FunctionalBlocks`. Сам по себе вызов не перерисовывает карту. |
| `Start()` | Отрисовывает сцену и запускает игровой цикл. Стрелки перемещают персонажа, `Esc` завершает цикл. |
| `Draw()` | Полностью очищает консоль и заново рисует все блоки и персонажа. |
| `MoveDraw(Pos oldpos)` | Обновляет изображение после шага: перерисовывает прежнюю клетку и персонажа. Обычно вызывается игровым циклом. |
| `ClearAll()` | Очищает список блоков и сбрасывает персонажа к стандартным значениям (`@`, белый цвет, `(0, 0)`). Не выполняет отрисовку. |
| `Nothing(Character character)` | Пустое действие-заглушка для блоков, которым не требуется обработчик. |

### `Pos`

`public readonly record struct Pos(int X, int Y)` — неизменяемая структура координат. Используется для позиции персонажа и клеток функциональных блоков.

Пример: `new TwoDism.Pos(10, 5)`.

### `Character`

Персонаж создаётся с тремя параметрами: символом, цветом и начальной позицией.

| Свойство | Тип | Описание |
|---|---|---|
| `Char` | `char` | Символ персонажа. |
| `CharacterColor` | `ConsoleColor` | Цвет символа персонажа. |
| `CharacterPos` | `Pos` | Текущие координаты персонажа. |
| `SelfDraw()` | метод | Рисует персонажа в текущей позиции с заданным цветом. |

Текущий экземпляр персонажа доступен через `TwoDism.Chr`.

### `FunctionalBlock`

Конструктор принимает **шесть** параметров в следующем порядке:

```csharp
FunctionalBlock(
    char chr,
    ConsoleColor color,
    List<Pos> positions,
    Action<Character> act,
    bool iswalkable,
    bool disposable
)
```

| Параметр конструктора | Тип | Описание |
|---|---|---|
| `chr` | `char` | Символ, которым рисуется блок. |
| `color` | `ConsoleColor` | Цвет символа блока. |
| `positions` | `List<Pos>` | Список клеток, занимаемых блоком. Один блок может занимать несколько клеток. |
| `act` | `Action<Character>` | Действие, вызываемое при взаимодействии с блоком. Получает текущего персонажа. Для блока без действия используйте `TwoDism.Nothing`. |
| `iswalkable` | `bool` | `true` — персонаж может перейти на клетку; `false` — переход блокируется. |
| `disposable` | `bool` | `true` — затронутая клетка удаляется из `Positions` при взаимодействии. Остальные клетки этого блока сохраняются. |

У `FunctionalBlock` также есть доступные для чтения и изменения свойства:

| Свойство | Тип | Описание |
|---|---|---|
| `Positions` | `List<Pos>` | Клетки блока. |
| `Char` | `char` | Символ блока. |
| `Color` | `ConsoleColor` | Цвет блока. |
| `Funct` | `Action<Character>` | Обработчик взаимодействия. |
| `IsWalkable` | `bool` | Разрешено ли перемещение на клетку блока. |
| `Disposable` | `bool` | Удалять ли затронутую клетку после взаимодействия. |
| `SelfDraw()` | метод | Рисует символ блока во всех координатах из `Positions`. |

**Важно:** в текущей версии у `FunctionalBlock` нет параметра или свойства `id`.

## Управление и границы карты

- `↑`, `↓`, `←`, `→` — перемещение на одну клетку.
- `Esc` — выход из игрового цикла.
- Границы перемещения определяются текущими `Console.WindowWidth` и `Console.WindowHeight`, а не отдельным размером карты.
- При попытке выйти за границы окна персонаж остаётся на прежней клетке.
- Любые другие клавиши не перемещают персонажа и не запускают взаимодействие с блоками.

## Как работает взаимодействие

При нажатии клавиши направления игровой цикл:

1. Вычисляет следующую клетку и проверяет, находится ли она внутри окна консоли.
2. Если персонаж действительно собирается перейти на другую клетку, находит все блоки, содержащие эту координату.
3. Для каждого найденного блока добавляет его обработчик в очередь действий. Если `Disposable == true`, удаляет одно вхождение целевой координаты из `Positions`.
4. Если хотя бы у одного найденного блока `IsWalkable == false`, перемещение отменяется. Иначе персонаж переходит на целевую клетку.
5. Вызывает все собранные обработчики в порядке расположения блоков в `FunctionalBlocks`.
6. Обновляет изображение в консоли.

Из этого следуют важные особенности:

- **Действие непроходимого блока тоже вызывается.** Персонаж не входит на его клетку, но обработчик срабатывает при попытке перейти на неё.
- **Обработчик вызывается после проверки перемещения.** Для проходимого блока `CharacterPos` обычно уже указывает на целевую клетку; для непроходимого — остаётся на прежней.
- **На одной клетке может находиться несколько блоков.** Будут обработаны все найденные блоки; если хотя бы один из них непроходим, персонаж не переместится.
- **Одноразовость применяется к отдельной клетке.** При взаимодействии удаляется только целевая координата из `Positions`, а не весь объект `FunctionalBlock`.
- **Клетка удаляется до вызова обработчиков и независимо от проходимости.** Поэтому одноразовый непроходимый блок тоже теряет затронутую клетку.
- Если целевая позиция совпадает с текущей (например, при нажатии неизвестной клавиши или у границы окна), взаимодействие не запускается.

## Примеры действий

Поскольку обработчик имеет тип `Action<TwoDism.Character>`, он может изменять свойства персонажа или состояние игры.

Изменить символ персонажа:

```csharp
static void ChangeSymbol(TwoDism.Character character)
{
    character.Char = '!';
}
```

Переместить персонажа в другую координату:

```csharp
static void Teleport(TwoDism.Character character)
{
    character.CharacterPos = new TwoDism.Pos(5, 5);
}
```

Для действия можно использовать любой метод с совместимой сигнатурой или лямбда-выражение.

## Особенности и ограничения

- **Одна общая игровая сцена:** `Chr` и `FunctionalBlocks` — статические данные `TwoDism`.
- **Ручная сборка карты:** создавайте блоки и добавляйте их через `AddBlock()` до вызова `Start()`.
- **Цветной вывод:** цвет символа задаётся через `ConsoleColor` и сбрасывается после каждой отрисовки.
- **Размер карты связан с окном консоли:** отдельная система камер, прокрутки или координат карты в коде не реализована.
- **Ответственность за координаты лежит на вызывающем коде:** при создании блоков и изменении `CharacterPos` используйте координаты внутри окна консоли, иначе методы отрисовки могут столкнуться с недопустимой позицией курсора.
