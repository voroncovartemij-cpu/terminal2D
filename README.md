# TwoDism

**TwoDism** — это легковесный C#-модуль для создания терминальных игр (движков, roguelike и квестов), позволяющий реализовать интерактивную карту и объекты прямо в консоли.

## Установка

1. Откройте папку вашего проекта.
2. Перенесите файл `World.cs` в папку проекта.
3. Готово!

## Использование

Главный класс модуля предоставляет следующие инструменты для управления игрой:

* `Start()` — метод, который запускает основной игровой цикл и отслеживает нажатия клавиш.
* `Draw()` — метод, отвечающий за полную очистку консоли и отрисовку всех объектов на карте.
* `Chr` — объект управляемого персонажа (класс `Character`). Содержит координаты, символ и цвет игрока.
* `FunctionalBlocks` — список (`List<FunctionalBlock>`) всех интерактивных блоков на карте. 

### Создание своего блока

Вы можете легко добавлять свои объекты (стены, ловушки, монеты) в список `FunctionalBlocks`. 

Пример создания нового блока:
```csharp
D2.FunctionalBlocks.Add(new D2.FunctionalBlock(
    id: 6,
    chr: '\$',
    color: ConsoleColor.Green,
    positions: new List<D2.Pos> { new D2.Pos(15, 10) },
    act: () => Console.Title = "Деньги собраны!",
    iswalkable: true,
    disposable: true
));
```

## Особенности архитектуры
* **Физика объектов:** Поддержка проходимости блоков (`IsWalkable`).
* **Триггеры событий:** Использование делегатов `Action` для вызова кастомного кода при наступлении на блок.
* **Одноразовые объекты:** Параметр `Disposable` автоматически удаляет объект с карты после взаимодействия.
