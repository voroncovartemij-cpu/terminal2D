# TwoDism

**TwoDism** — это легковесный C#-модуль для создания терминальных игр (движков, roguelike и квестов), позволяющий реализовать интерактивную карту и объекты прямо в консоли.

## Требования

* .NET 8 или новее (используются primary constructors и collection expressions из C# 12).

## Установка

1. Откройте папку вашего проекта.
2. Перенесите файл `TwoDism.cs` в папку проекта.
3. Готово! Весь код модуля находится в статическом классе `TwoDism`.

## Быстрый старт

В `Program.cs` опишите действие блока, добавьте блоки и запустите игру:

```csharp
// Действие блока: получает персонажа, на которого сработал блок
static void ChangeColor(TwoDism.Character character)
{
    character.CharacterColor = character.CharacterColor == ConsoleColor.Green
        ? ConsoleColor.White
        : ConsoleColor.Green;
}

// Непроходимая стена без действия
TwoDism.AddBlock(
    new(
        1,                              // id
        '#',                            // символ
        ConsoleColor.Red,               // цвет
        [new TwoDism.Pos(10, 10)],      // позиции на карте
        TwoDism.Nothing,                // действие (заглушка)
        false,                          // проходимый?
        false                           // одноразовый?
    )
);

// Одноразовая монета, меняющая цвет игрока
TwoDism.AddBlock(
    new(
        2,
        '$',
        ConsoleColor.Green,
        [new TwoDism.Pos(20, 10)],
        ChangeColor,
        true,
        true
    )
);

TwoDism.Start();
```

Управление: **стрелки** — движение, **Esc** — выход.

## API

* `Start()` — запускает игровой цикл и отслеживает нажатия клавиш.
* `AddBlock(FunctionalBlock)` — добавляет блок на карту.
* `Draw()` — очищает консоль и отрисовывает все блоки и игрока.
* `Chr` — управляемый персонаж (`Character`): `CharacterPos`, `Char`, `CharacterColor`.
* `FunctionalBlocks` — список всех блоков на карте.
* `Nothing` — функция-заглушка для блоков без действия.
* `Pos(X, Y)` — неизменяемая структура координат (`readonly record struct`).

### Параметры `FunctionalBlock`

| Параметр | Тип | Описание |
|---|---|---|
| `id` | `int` | Идентификатор блока |
| `chr` | `char` | Символ, которым блок рисуется |
| `color` | `ConsoleColor` | Цвет символа |
| `positions` | `List<Pos>` | Все клетки, которые занимает блок |
| `act` | `Action<Character>` | Действие, вызываемое при взаимодействии. Получает игрока |
| `iswalkable` | `bool` | `true` — на блок можно встать, `false` — блок непроходим |
| `disposable` | `bool` | `true` — клетка блока исчезает с карты после взаимодействия |

## Как работает взаимодействие

За одно нажатие клавиши игровой цикл делает следующее:

1. Вычисляет клетку, на которую хочет шагнуть игрок. Выход за границы окна запрещён.
2. Ищет все блоки на этой клетке. Если хотя бы один из них непроходим, игрок остаётся на месте.
3. Если блок одноразовый, его клетка удаляется с карты.
4. Перемещает игрока (если шаг разрешён).
5. **После шага** вызывает действия найденных блоков по порядку их добавления.

Из этого следует:

* Действие может менять игрока, в том числе позицию. Например, телепорт: `character.CharacterPos = new(x, y);`.
* Действие непроходимого блока тоже срабатывает: при попытке пройти сквозь него («удар»).
* На одной клетке может быть несколько блоков, сработают все.
* Если игрок не сдвинулся (упёрся в край экрана или нажал другую клавишу), блоки не срабатывают повторно.

## Особенности архитектуры

* **Физика объектов:** поддержка проходимости блоков (`IsWalkable`).
* **Триггеры событий:** делегаты `Action<Character>` позволяют вызвать любой код, имеющий доступ к игроку.
* **Одноразовые объекты:** параметр `Disposable` автоматически убирает клетку с карты после взаимодействия.
* **Данные отдельно от движка:** карта собирается снаружи через `AddBlock`, файл модуля менять не нужно.
